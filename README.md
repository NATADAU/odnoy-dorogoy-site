# «Одной дорогой»

Концепция нового сайта АНО СК «Одной дорогой» — социального клуба в Коломне.

В макете есть:

- обычная версия текстов и режим «Ясный язык»;
- информация об организации и проектах;
- новости и отзывы;
- публичные отчёты;
- структурированный раздел «Соцреестр»;
- полезные ссылки, контакты и форма обратной связи.

## Запуск на компьютере

Потребуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу `http://localhost:3000`.

## Публикация

Репозиторий подготовлен для GitHub Pages. После включения Pages сайт будет
автоматически собираться при каждом обновлении ветки `main`.

Тексты ясной версии, новости, отзывы и точные ссылки на документы пока являются
демонстрационными и должны быть заменены согласованными материалами.
